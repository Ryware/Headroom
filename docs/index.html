It watches, so you do not have to.

Headroom sits in the menu bar and records free space on your startup disk while it runs. When space gets low it tells you, and the fix is one click away.

  2. A local notification. No account, no cloud. Just macOS telling you the disk is low and how much is safe to clean.
  3. One click. Caches, logs and build output that macOS and your tools recreate on their own go to the Trash. Nothing else.

Know before you delete

Every recognized item gets a plain-language verdict and a note on what deleting it affects.

Safe

Regenerable data such as caches, build output and package stores.

Usually safe

Rebuilt on demand, may take a while or a re-download to recreate.

Check first

Settings or user data. Read the note in the Inspector before removing.

Never

Keychains, Mail, Photos library, the system itself. Headroom will tell you so.

Up and running in a minute

With Homebrew, paste this into Terminal:

brew install ryware/tap/headroom

Update with brew upgrade headroom. Uninstall with brew uninstall headroom.

Or download it yourself:

  1. 1
    Download the DMG from GitHub Releases. Signed with a Developer ID and notarized by Apple.
  2. 2
    Drag Headroom to Applications and open it.
  3. 3
    Scan a folder, your home folder or the whole startup disk.
  4. 4
    Clean what the safety verdicts say is safe.

macOS 14 Sonoma or newer, Apple silicon and Intel. Prefer to build it yourself? git clone and run ./build.sh run.

Questions

Short answers. The README has the long ones.

Can I install Headroom with Homebrew?

Yes. Run brew install ryware/tap/headroom in Terminal. It installs the same signed, notarized app as the DMG. Update with brew upgrade headroom, uninstall with brew uninstall headroom, or use brew uninstall --zap headroom to also remove its settings and history. If you don't have Homebrew yet, the one-line installer is on brew.sh.

Is there a Pro version of Headroom?

No. There is no Pro tier, subscription, lifetime purchase, trial or in-app purchase. Every feature is free and unlocked for everyone: the treemap, one-click cleanup, developer deep scan, safety hints, Trash-first deletion and fast permanent deletion.

Is there a free Mac disk cleaner with no subscription?

Yes, this one. Headroom is a free, open-source Mac disk space analyzer and cleaner that never locks cleanup or developer scans behind a paywall, and never asks for an account or payment.

How does the duplicate finder work?

Files are grouped by size, then by a hash of their first 64 KB, then by samples from the middle and end, then by a full SHA-256 of the whole file. Only files that still match after the last step are listed, so every group is byte-for-byte identical. Files under 1 MB and files inside app bundles are skipped, and Headroom always keeps one copy of each file unless you turn that guard off.

What is Headroom?

Headroom is a free, open-source, native macOS app that shows what is using space on your Mac. It scans a folder or disk, visualizes the result as a folder tree, treemap and category charts, explains whether items are safe to delete and helps you clean them up.

Is Headroom really free?

Yes. It is MIT-licensed with no ads, subscriptions, accounts, in-app purchases or analytics. It was made to be enjoyed.

How do I see what is taking up space on my Mac?

Open Headroom, choose Home or Startup Disk and wait for the scan. The dashboard shows free and used space and the biggest categories, the folder tree lists folders by size, and the treemap draws every file as a rectangle sized by how much space it uses.

Is it safe to delete node_modules, DerivedData or cache folders?

Usually yes, because they are regenerable: node_modules can be reinstalled, Xcode DerivedData is rebuilt on the next build and caches are recreated on demand. Headroom labels recognized items Safe, Usually safe, Caution or Never and explains the effect. Keep Trash mode on if you want to be able to undo.

What is the difference between Trash and Permanent mode?

Trash mode moves items to the macOS Trash so you can restore them until you empty it. Permanent mode removes them immediately with a fast parallel engine like rimraf and cannot be undone.

How fast is Headroom?

It uses getattrlistbulk(2) and scans directories in parallel across all cores. On an M3 Pro, a home folder with about 1.07 million files and 167,000 folders (102 GB) scanned in about 16 seconds. See how it compares.

Does Headroom send my data anywhere?

No. Scanning and analysis happen entirely on your Mac. There is no account system, analytics SDK or cloud service in the app. This website uses Google Analytics to count visits and downloads; the app itself sends nothing.

Is there a WizTree or TreeSize alternative for Mac?

Headroom is a free, native Mac app in the same spirit: a fast scan, a sortable size tree and a treemap, plus safety explanations and one-click developer cleanup.

Is there a free alternative to DaisyDisk?

Headroom is a free, open-source option if you want a DaisyDisk-style visual map of your disk without paying. DaisyDisk is a paid app with a sunburst map; Headroom uses a treemap and a sortable folder tree, and adds a duplicate finder, safety explanations and developer cleanup.

How is Headroom different from GrandPerspective?

Both are open source and both draw a treemap of your disk. GrandPerspective focuses on the treemap view. Headroom adds a sortable folder tree, category breakdown, duplicate finder, safety explanations for what you are about to delete, one-click developer cleanup and a menu bar monitor.

Is Headroom the same app as DiskTree?

No. Headroom was called DiskTree before version 1.0, but it is not related to the DiskTree app sold at disktree.org. That DiskTree is a closed-source treemap app with a free tier and a paid Pro plan for cleanup. Headroom is free and open source, with cleanup, a duplicate finder and Safe / Caution / Never verdicts included. Scanning the same 102 GB home folder on an M3 Pro, Headroom took about 16 seconds and DiskTree 1.1.3 about 58. See the full benchmark.

How is Headroom different from Mole?

Both are free and open source. Mole is a terminal cleaner whose mo analyze command shows disk usage; Headroom is a native app with a folder tree, treemap, duplicate finder and a Safe / Caution / Never verdict for each known folder. Scanning the same 102 GB home folder on an M3 Pro, Headroom finished a full scan in about 16 seconds and Mole in about 24, and Headroom listed every one of the 1.07 million files. Mole uses far less memory and answers repeat scans from a cache in about 4 seconds, and it also uninstalls apps and optimizes the system, which Headroom does not. See the full benchmark.

Is Headroom a free alternative to CleanMyMac?

For finding and freeing disk space, yes. Headroom covers disk analysis, large files, duplicates and cache and developer cleanup for free, with no subscription. It is not a full maintenance suite: it has no malware scanner, app uninstaller or performance tools.

What are the system requirements?

macOS 14 Sonoma or newer on Apple silicon or Intel. Full Disk Access is only needed for protected locations such as Mail, Messages and Safari data.

Headroom says it does not have permission to move a folder to the Trash. What now?

This almost always comes from an antivirus or ransomware shield (AVG, Avast, Bitdefender, Norton and similar). They guard Documents, Desktop, Downloads and Pictures and refuse unknown apps that change files there, and macOS reports it with the same words as a real permission problem. Add Headroom to the product’s allowed apps:

  • AVG and Avast: Menu › Settings › General › Blocked & Allowed Apps › Allow app › Headroom.
  • Bitdefender: Protection › Anti-Ransomware › Safe Files › Manage Applications › set Headroom to Allowed.
  • Managed work Mac (CrowdStrike, SentinelOne, Jamf Protect): ask IT to allow the app.

Or click Reveal in Finder in the result and delete the item there: Finder is always allowed. Headroom also looks for installed security products, names the likely one in the result with the setting to change, warns before a delete inside a guarded folder, and shows an Open button for that product. If no security product is installed, check System Settings › Privacy & Security › Files and Folders, and whether the item belongs to another user.
